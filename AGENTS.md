# CoolCharge build notes

This workspace builds a SpringBoard tweak and a PreferenceLoader bundle with `apelin_project_build`. The build invokes `apelin/build.sh`, which compiles `Sources/Tweak.m` and `Sources/Prefs.m` for the requested bootstrap, links Foundation/UIKit/IOKit and the Apelin Preferences stub, signs both Mach-O files with `ldid -S`, writes the SpringBoard filter and PreferenceLoader entry, and creates exactly one package artifact with `dpkg-deb` in Apelin's package folder.

The tweak reads IOKit power-source telemetry and AppleSmartBattery temperature, uses a learned charging-rate estimate for the Lock Screen panel, and applies only a conservative process-priority adjustment to SpringBoard while charging. It does not write private charging-controller properties or alter charging current/voltage. Charging start/stop timestamps and duration are persisted in the mobile preferences domain and are shared with the live Settings preview.

The Settings pane is `CoolChargePrefs.bundle` under `/Library/PreferenceBundles/`; its controls post `com.ilyastekdin.coolcharge/changed`, refresh the preview every second while visible, and expose enable/disable, widget, session-time, temperature, receipt, and history-reset controls. The package also installs `Packaging/entry.plist` under `/Library/PreferenceLoader/Preferences/` and depends on `preferenceloader` in addition to `mobilesubstrate`.
