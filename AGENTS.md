# CoolCharge build notes

This workspace builds a SpringBoard tweak and a PreferenceLoader bundle with `apelin_project_build`. The build invokes `apelin/build.sh`, which compiles `Sources/Tweak.m` and `Sources/Prefs.m` for the requested bootstrap, links Foundation/UIKit/IOKit and the Apelin Preferences stub, signs both Mach-O files with `ldid -S`, writes the SpringBoard filter and PreferenceLoader entry, and creates exactly one package artifact with `dpkg-deb` in Apelin's package folder.

The tweak follows Jikan's current Cover Sheet lifecycle architecture without copying its GPL-3.0 source wholesale: it attaches a non-interactive charging platter to `CSCoverSheetView`, uses a blur/material fallback and safe-area-aware placement, and updates only while the host is visible. It reads IOKit power-source telemetry and AppleSmartBattery temperature, uses a learned charging-rate estimate, and applies only a cooperative SpringBoard process-priority adjustment. The thermal guard samples once per second, ramps before a configurable 36.5°C default battery-temperature ceiling, escalates at the ceiling, and can remain active while the Cover Sheet is visible and the device is hot even when it is not charging. It never writes private charging-controller properties or alters charging current/voltage; iOS remains responsible for hardware throttling and PMIC policy. Charging start/stop timestamps and duration are persisted in the mobile preferences domain and are shared with the live Settings preview.

The Settings pane is `CoolChargePrefs.bundle` under `/Library/PreferenceBundles/`; its controls post `com.ilyastekdin.coolcharge/changed`, refresh the preview every second while visible, and expose enable/disable, the 32–42°C thermal ceiling, locked-state protection, widget, session-time, temperature, receipt, and history-reset controls. The package also installs `Packaging/entry.plist` under `/Library/PreferenceLoader/Preferences/` and depends on `preferenceloader` in addition to `mobilesubstrate`.
